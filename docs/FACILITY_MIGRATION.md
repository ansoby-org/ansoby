# 茅ヶ崎市 施設・区画名称 移行対応表

## 概要

旧公共施設予約システム（Cultos）から新予約システム（p-kashikan）への施設・区画名称の移行対応表です。

新システムでは facility（施設） → room（部屋） → section（区画）の階層構造で管理されます。

## 実装方針

### identityの保持

表示名そのものをidentityにせず、新システム側の安定した施設/室/区画コードをidentityとして保持します。
これにより将来表示名が変更されても同一区画として追跡できます。

```javascript
{
  facilityCode: '001',     // 施設コード
  facilityName: '総合体育館',
  room: '体育室1',          // 部屋名
  section: '1',            // 区画番号（全面の場合はnullまたは'全面'）
  date: '2026-09-25',
  time: '10:00',
  status: 'available'
}
```

### 差分検出キー

複数区画を独立して追跡するため、差分検出キーには facility + room + section を含めます：

```javascript
`${facilityCode}:${room}:${section || 'default'}:${date}:${time}`
```

## 注意事項

1. **新システムを正本とする**: 旧 `ansoby/court_reservation` の設定は参考として参照しますが、名称・区画構造については新システムを正本にしてください。

2. **コードベースのidentity**: 表示名は変更される可能性があるため、可能な限り新システム側の安定した施設/室/区画コードをidentityとして保持してください。

3. **階層構造の維持**: 概念的には `facility -> room -> section` の階層を保持し、将来の拡張性を確保してください。

4. **fail-closedの維持**: 新しい施設・部屋・区画を追加する際も、fail-closed設計を維持してください。HTML構造が期待と異なる場合はエラーを投げるようにしてください。
