### 2. 実装方式

#### HTMLパース方式の採用理由

p-kashikanシステムは公式APIを提供していないため、以下の方式を採用:

1. **HTTPリクエスト**: fetch APIを使用してWebページを取得
2. **HTMLパース**: 正規表現でHTML要素から情報を抽出
3. **データ構造化**: 統一されたJSONフォーマットに変換

#### パース対象の要素

```html
<!-- 施設一覧 -->
<a href="index.php?facility_id=101">施設名</a>

<!-- 空き状況 -->
<td class="available" data-date="2026-09-25" data-time="09:00"></td>
<td class="reserved" data-date="2026-09-25" data-time="10:00"></td>

<!-- 施設詳細 -->
<h1>施設名</h1>
<p>住所: 茅ヶ崎市...</p>
<p>定員: 300名</p>
```

### 3. エラーハンドリング戦略

#### タイムアウト設定
- デフォルト: 30秒
- AbortControllerを使用した中断処理

#### エラーの分類
1. **パラメータエラー**: 入力検証で早期検出
2. **ネットワークエラー**: リトライ可能
3. **HTTPエラー**: ステータスコード別処理
4. **パースエラー**: 空の結果を返す

### 4. データモデル

#### Facility（施設情報）
```typescript
{
  id: string;          // 施設ID
  name: string;        // 施設名
  provider: string;    // 'chigasaki'
  system: string;      // 'new' | 'old'
}
```

#### Availability（空き状況）
```typescript
{
  facilityId: string;     // 施設ID
  date: string;           // YYYY-MM-DD
  time: string;           // HH:MM
  status: string;         // 'available' | 'reserved'
  provider: string;       // 'chigasaki'
  timestamp: string;      // ISO 8601
}
```

## 実装者メモ

### HTMLパースのポイント

1. **正規表現の使用**
   - グローバルフラグ (`/g`) で全マッチを取得
   - ケースインセンシティブ (`/i`) で大文字小文字を無視

2. **重複の除去**
   - MapとSpread演算子で重複施設を除去
   - `[...new Map(facilities.map(f => [f.id, f])).values()]`

3. **ソート処理**
   - 日付→時刻の順でソート
   - localeCompareで文字列比較

### 注意点

- システムの仕様が変更される可能性がある
- アクセス頻度に注意（過度なリクエストを避ける）
- エラーログの記録と監視が重要
- ユーザーへの適切なエラーメッセージ
